## 데이터 범위

- Highlightly 검색은 영문 이름 기반, 한 페이지에 최대 12명입니다.
- 실제 선수 목록의 리그·팀·포지션·시즌 필터와 홈 득점·도움 순위는
  **이 브라우저에서 확인하고 저장한 실제 선수**만 대상으로 합니다.
  제공업체 전체 선수 검색 또는 리그 전체 순위라고 표시하지 않습니다.
- 실제 선수 원본 기록과 학습용 Mock Data는 합치지 않습니다.
- 프로필 사진·나이·등번호 등은 제공된 정보만 사용합니다. 등번호는 경기별 데이터에 따라 다릅니다.
- 시즌 상세 합계는 조회된 종료 경기의 출전 기록을 합산합니다.
  목록 제한·실패·미출전/미제공을 표시하며 누락값을 0으로 채우지 않습니다.
- 역할 점수는 공개한 규칙·목표값과 가중치로 계산한 학습용 지수입니다.
  리그의 실제 분포로 학습한 모델이나 경기 결과 예측이 아닙니다.
- 백분위는 저장된 같은 시즌·대회 유형·포지션의 선수 표본 내 순위입니다.
  지표별 최소 5명, 선수별 3경기·270분을 충족하지 않으면 계산하지 않습니다.
  리그 전체 백분위가 아닙니다.
- 선수 및 비교 선택은 해당 브라우저의 localStorage에 저장됩니다.
  서버 계정 동기화나 공유 데이터베이스는 포함하지 않습니다.
- 경기 목록 캐시는 15분, 나머지 응답은 24시간 재사용하며 로컬 파일에도 저장합니다. 한도 차단과 저장된 응답은 개발 서버 재시작 이후에도 유지됩니다.
  유료 요청 제한 해제나 자동 주기 수집은 하지 않습니다.

## 검증

- `npm run build`: TypeScript 및 배포 산출물 빌드
- `npm run lint`: Oxlint
- `npm test`: 집계, 누락값, 90분당, 성공률, 역할 점수, 여섯 대결 조합,
  표본 백분위, 비교 선택, API 입력 검증·캐시·오류 보호 등
- 실제 API: 홀란 프로필, 리그 9경기, 포든 출전 7경기, 기본 기록과 상세 기록 수신
- 브라우저: 검색·상세·비교 경로, 세 가지 비교 모드, 기록 단위 전환, Recharts 차트
- 모바일: 320px 및 390px에서 문서 가로 넘침 없이 표 내부 스크롤

## 배포 전 별도 운영 작업

공개 배포, 서버 영속 저장소, 사용자 계정, 운영용 요청량 정책은 이번 로컬 개발 범위에 포함하지 않습니다.
